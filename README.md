# בניית APK בענן (בלי מחשב)

## מה צריך
1. חשבון GitHub (חינמי).
2. הקובץ ה-HTML שלך, שמו משתנה ל-`index.html`.

## שלבים
1. צור Repository חדש ב-GitHub (למשל `moti-apk`).
2. העלה את כל התיקייה הזו (כולל `.github`). אפשר לגרור קבצים בדפדפן של GitHub.
3. החלף את `app/src/main/assets/index.html` בקובץ ה-HTML שלך (עם השם `index.html`).
4. לשונית **Actions** -> **Build APK** -> **Run workflow**.
5. אחרי כמה דקות, הורד את **moti-debug-apk** מתחת לריצה, פתח את ה-ZIP, והתקן את ה-APK.
6. בטלפון צריך לאשר "התקנה ממקורות לא ידועים" לפעם הראשונה.

## הערות חשובות
- זה APK של **debug** (חתימה לבדיקה). מתאים להתקנה אישית. לא מתאים לחנות Google Play.
- המפתחות שבתוך ה-HTML נשארים בתוך ה-APK. מי שמקבל את ה-APK יכול לחלץ אותם, אז אל תשתף אותו עם מפתחות אמיתיים.
- הקוד לא נבנה ונבדק בסביבה שלי (אין לי Android SDK ואין גישה לרשת). הבנייה הראשונה עשויה לדרוש תיקון קטן. אם היא נכשלת, שלח לי את הודעת השגיאה מלשונית Actions.
